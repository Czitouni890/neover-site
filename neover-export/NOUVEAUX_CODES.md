# Site NEOVER multipage

Ce dossier contient la version modifiee et complete du site NEOVER.

## Pages

- `index.html` : page Accueil
- `qui-sommes-nous.html` : page Qui sommes-nous
- `services.html` : page Services
- `contact.html` : page Contact
- `mentions-legales.html` : page Mentions legales

## Nouveaux fichiers

- `assets/multipage.js`
  - transforme la navigation en vraies pages separees ;
  - ajoute les liens Accueil, Qui sommes-nous, Services, Contact et Mentions legales ;
  - complete automatiquement la navigation du pied de page ;
  - retire les mentions legales du contenu de l'accueil ;
  - surligne la page active.

- `assets/multipage.css`
  - affiche uniquement le contenu correspondant a chaque page ;
  - masque les sections secondaires sur l'accueil ;
  - gere le style des liens actifs.

## Fichiers synchronises

- `assets/index-P_zLiGVh.css` : styles actuels du site public.
- `sitemap.xml` : URLs des nouvelles pages.
